The Inverted Search Project is designed to perform efficient text searching across multiple files by creating an inverted index.
Instead of searching every file repeatedly, the program stores indexed words in a hash table structure for quick retrieval.

The project demonstrates concepts like:

.Hash Tables

.Linked Lists

.File Handling

.Dynamic Memory Allocation

.Searching Algorithms

✨ Features


📂 Create database from multiple text files

🔍 Search words quickly across indexed files

📋 Display complete database contents

💾 Save database into backup file

🔄 Update database from saved backup

🔠 Case-insensitive searching

⚡ Efficient indexing using hash tables
